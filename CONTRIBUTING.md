# Contributing to /brag — Arabic Edition | دليل المساهمة

Thank you for your interest in improving `/brag — Arabic Edition`!  
شكراً لاهتمامك بالمساهمة في تطوير النسخة العربية من `/brag`.

We welcome contributions from developers, linguists, and creators worldwide.

---

## Areas We Welcome Help With | مجالات المساهمة

1. **Dialect Vocabularies & Idioms (إثراء اللهجات)**
   - Refining colloquial phrasing for Moroccan Darija, Iraqi, Sudanese, and Algerian dialects.
   - Ensuring modern tech startup slang sounds natural and culturally resonant.

2. **RTL Typography & Motion Design (التصميم والخطوط العربية)**
   - Suggesting open-source Arabic fonts on Google Fonts that pair well with different tones.
   - Enhancing CSS animations for RTL text reveal, transitions, and timing.

3. **Audio & Sound Cues (المؤثرات الصوتية)**
   - Suggesting royalty-free (CC0) ambient/rhythm tracks that complement Arabic video pacings.

4. **Agent Compatibility (التوافق مع وكلاء الذكاء الاصطناعي)**
   - Testing compatibility with emerging coding agents (Windsurf, Cline, Roo Code, Aider).

---

## How to Submit a Contribution | خطوات إرسال المساهمة

1. **Fork the repository** or create a branch:
   ```bash
   git checkout -b feature/my-new-dialect
   ```
2. **Make your changes** (e.g. updating `references/tones.md` or `SKILL.md`).
3. **Open a Pull Request** with a brief summary of the changes in either Arabic or English.

---

## Code of Conduct | ميثاق السلوك

Be respectful, welcoming, and inclusive to all contributors.
